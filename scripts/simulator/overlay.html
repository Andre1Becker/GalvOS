GalvOS Simulator

This is an interactive browser-based simulator for the GalvOS open-source ESP32-S3 RGB laser galvo controller. All data is mocked — no real hardware is connected.

GalvOS replaces the proprietary OEM board in OEM RGB laser projectors, controlling two galvanometers via a DAC8562 SPI DAC. The firmware runs on PlatformIO / Arduino (ESP32-S3-WROOM-1 N16R8).
