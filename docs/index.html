About

All 81 firmware presets are re-implemented in JavaScript from src/patterns/preset_patterns.cpp and rendered through a simplified version of the point optimizer and the live post-processing chain (3-axis rotation, kaleidoscope, mirror, color override, dimmer). Coordinates use the firmware DAC space of ±32768 units with +Y up. The simulation is an approximation — real galvo inertia, ringing compensation and velocity clamping are not modelled.
