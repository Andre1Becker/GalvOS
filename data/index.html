Corner Handling

Minimum exterior angle to treat a vertex as a corner and add dwell points; lower values catch gentler bends too.

Dwell points added at the softest qualifying corner.

Interior Density

Interior point density — points added per 1000 DAC units of segment length.

Interior points reserved per segment before the blank-jump budget is computed.

Frame Budget

Only feeds the Smart Defaults calculation below — has no direct effect of its own.

Total point budget per frame; density scales down uniformly once this is exceeded.

Blank Jumps

Ceiling for distance-proportional blank-jump sample count.

Floor for blank-jump samples, plus the landing settle dwell.

Rate at which the blank-jump sample count scales with jump distance.

First fallback blank-sample count when a frame goes over budget, before the hard minimum above.

Resample

Replaces length-proportional density with constant point spacing along every edge.

Target spacing between resampled points, in DAC units. Only used while Resample is enabled.

Ringing Compensation

Zero-Vibration (ZV) input shaping on blank jumps — measure your galvo's resonance before enabling.

Galvo mechanical resonant frequency in Hz — must be measured on real hardware.

Galvo damping ratio ζ — must be measured on real hardware (typical 0.05–0.3).

Jitter

Perpendicular point displacement for a hand-drawn line texture instead of laser-perfect edges.

Maximum perpendicular jitter offset, in DAC units.

Scanner Protection

Subdivides any lit step exceeding Max Step so the galvo is never asked to jump further than it can follow in one tick.

Limits how quickly commanded velocity can change between ticks, to avoid exciting galvo resonance.

Jump Order

Nearest-neighbour blank-jump ordering across a call's segments (wireframes, text, paint) — shortens total jump distance instead of visiting them in input order. Closed shapes may rotate their start vertex; open segments may be traversed backwards.
